# Página inicial

Use a [!UICONTROL Página inicial] em [!DNL Adobe Marketo Optimizer] para iniciar conversas de IA, habilidades de inicialização e abrir espaços de trabalho de marketing. Selecione **[!UICONTROL Página inicial]** na navegação para retornar a esta página.

A mensagem de boas-vindas personalizada pergunta sobre suas tarefas atuais. Escolha como começar com a entrada de conversa, opções de intenção, cartões de acesso rápido ou cartões de habilidade.

Assista ao vídeo para um tour pela página inicial e pelo espaço de trabalho de marketing. As seções a seguir fornecem instruções escritas.

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## Iniciar uma conversa sobre IA

Use a entrada [!UICONTROL Fazer uma pergunta ou iniciar uma tarefa] para começar a trabalhar com o [!UICONTROL Colaborador]. Digite `/` para procurar habilidades e comandos.

1. Insira uma pergunta ou descreva a tarefa que deseja concluir.
1. Para fornecer material de suporte, selecione **[!UICONTROL Anexar]** na entrada e anexe um arquivo.
1. Envie seu prompt para continuar no painel [!UICONTROL Colaborador].

A página inicial também fornece quatro opções de intenção para iniciar o trabalho.

| Opção | Meta |
| -------- | ------ |
| [!UICONTROL Plano] | Planejar atividades de marketing. |
| [!UICONTROL Create] | Crie conteúdo ou recursos de marketing. |
| [!UICONTROL Medida] | Revise o desempenho de marketing. |
| [!UICONTROL Otimizar] | Refinar atividades de marketing existentes. |

Para obter mais informações, leia sobre a [interface de chat](/help/user-guide/agents/chat-interface.md).

## Acesso rápido

Selecione um cartão de [!UICONTROL Acesso rápido] para abrir um espaço de trabalho ou examinar a integridade da decisão da IA.

| Cartão | O que você pode acessar |
| ------ | --------------------- |
| [Integridade da decisão de IA](/help/user-guide/agents/ai-decisioning-health.md) | Volume da história e a porcentagem de pessoas classificadas por persona. |
| [Marketing](/help/user-guide/marketing/marketing-management.md) | Programas, jornadas de pessoas e listas de pessoas no espaço de trabalho de marketing. |
| [!UICONTROL Ativos] | Ativos de conteúdo para emails e páginas. |
| [!UICONTROL Relatórios] | Relatórios de desempenho e envolvimento. |

## Habilidades

Selecione um cartão em [!UICONTROL Habilidades] para iniciar um fluxo de trabalho de IA específico.

| Habilidade | Meta |
| ------- | ------ |
| [!UICONTROL Criar públicos-alvo com base em persona] | Gere públicos usando sinais de persona e ajuste firmográfico. |
| [!UICONTROL Criar programas omnicanal] | Componha programas em e-mail, Web e destinos a partir de um resumo. |
| [!UICONTROL Criar emails hiperpersonalizados] | Rascunho de emails personalizados com tokens e blocos de conteúdo dinâmico. |
| [!UICONTROL Controle de tráfego de jornada baseado em intenção e ajuste] | Rotear contatos entre jornadas usando sinais de ajuste e intenção de conta. |

Você também pode procurar habilidades de agente em [!UICONTROL Colaborador]. O vídeo mostra a caixa de diálogo [!UICONTROL Usar uma habilidade do agente], com um campo de pesquisa e filtros de categoria. Para obter detalhes, leia sobre [habilidades do agente](/help/user-guide/agents/skills.md).

## Navegar para espaços de trabalho

Use a navegação do aplicativo para abrir as seguintes áreas de trabalho na página inicial ou no espaço de trabalho de marketing.

| Área de trabalho | O que você pode acessar |
| ----------- | --------------------- |
| [!UICONTROL Gerenciamento de marketing] | Programas, jornadas de pessoas e listas de pessoas. |
| [!UICONTROL controle de tráfego de Jornada] | [controle de tráfego de Jornada](/help/user-guide/marketing/journey-traffic-control.md). |
| [!UICONTROL Relatórios] | Relatórios de desempenho de marketing. |
| [!UICONTROL Gerenciamento de conteúdo] | [!UICONTROL Modelos], [!UICONTROL Assets], [!UICONTROL Fragmentos], [!UICONTROL Forms], [!UICONTROL Landing pages] e [!UICONTROL Webinar]. |
| [!UICONTROL Conexões] | [Destinos](/help/user-guide/audiences/destinations.md). |
| [!UICONTROL Laboratórios] | [Scoring Studio](/help/user-guide/labs/scoring-studio.md). |
| [!UICONTROL Administração] | [!UICONTROL Canais] e [!UICONTROL Tipos de programas]. |

## Explorar o espaço de trabalho de marketing

Selecione o cartão de acesso rápido **[!UICONTROL Marketing]** ou o **[!UICONTROL Gerenciamento de marketing]** na navegação para abrir o espaço de trabalho de marketing. Trabalhe com o [!UICONTROL Colaborador], abra recursos de marketing e retorne aos itens acessados recentemente sem retornar à página inicial.

1. Selecione **[!UICONTROL Programas]**, **[!UICONTROL jornadas de pessoas]** ou **[!UICONTROL Listas de pessoas]** no painel **[!UICONTROL Marketing]** para procurar recursos.
1. Selecione um recurso para abri-lo em uma guia Workspace. Como alternativa, selecione um item em **[!UICONTROL Acessado recentemente]**.
1. Para continuar trabalhando com recursos diferentes, alterne entre as guias abertas.

O painel [!UICONTROL Colaborador] reflete o recurso que você abre. Seus prompts podem direcionar um programa, lista de pessoas ou pessoa selecionada. Por exemplo, abrir um registro de pessoa fornece solicitações para explorar a atividade de persona e engajamento dessa pessoa.

Selecione **[!UICONTROL Recolher]** para ocultar o painel [!UICONTROL Colaborador] ou **[!UICONTROL Trocar painéis]** para alterar seu posicionamento. Para obter mais informações, leia sobre [gerenciamento de marketing](/help/user-guide/marketing/marketing-management.md) e [detalhes da pessoa](/help/user-guide/audiences/person-details.md).
