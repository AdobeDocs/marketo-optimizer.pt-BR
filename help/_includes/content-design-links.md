# Criação de conteúdo - rastreamento de links

O painel Rastreamento de link fornece uma visualização centralizada, onde você pode localizar facilmente cada URL no conteúdo. Clique no ícone _[!UICONTROL Links]_ ( ![Ícone Mostrar links](../user-guide/assets/do-not-localize/icon-links.svg) ) à esquerda para exibir todas as URLs vinculadas no seu conteúdo. Esses são os links dentro dos componentes de texto, botão ou imagem.

Para definir o rastreamento de um link de conteúdo listado, clique no ícone _Editar_ ( ![Editar ícone](../user-guide/assets/do-not-localize/icon-edit.svg) ) e modifique o **[!UICONTROL Tipo de Rastreamento]** ou o **[!UICONTROL Rótulo]**.
